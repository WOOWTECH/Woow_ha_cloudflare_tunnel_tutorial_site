Home Assistant Cloudflared Web GUI guide

No open ports, a safe way home

12-chapter Cloudflared Web GUI guide: from installing, Setup, Cloudflare authorization, hostname, Dashboard, Config and Logs, to security and troubleshooting. The Sales Handbook, Prompt Library and Skill Handbook are in the Resource Hub.

Basics: prepare and install

01

Before you start

First confirm your domain, Cloudflare DNS, your Home Assistant installation type, and the locally or remotely managed mode.

 02

Install the Web GUI

Add the WoowTech repository to the Apps store, install the add-on and leave it in a safe initial state.

 03

First open

Open the interface through Home Assistant Ingress and get to know Dashboard, Setup, Config and Logs.

Build: create a secure entrance

04

Setup wizard

Use the wizard to sort out the hostname, the tunnel mode and the authorization prerequisites, and do not rush to hit apply.

 05

Cloudflare authorization

Recognize the one-time authorization URL, pick the right domain, and avoid leaking the account certificate or the authorization link.

 06

Dashboard status

Learn to read the tunnel, edge connections and add-on status; observe first, then decide whether to act.

Manage: hosts and logs

07

Config settings

Understand how the Web GUI and Supervisor options stay in sync, and tell apart the scope of impact of each setting.

 08

External hostname

Plan the Home Assistant public hostname, the trusted proxy and the end-to-end acceptance check.

 09

Additional hosts

Expose only the local services you really need, and understand hostname, service and the DNS cleanup after a deletion.

Maintain: security and troubleshooting

10

Logs and maintenance

Use the live log, filtering and download to build a repeatable health-check routine.

 11

Security checks

Check the entrance, accounts, hostname, DNS and the Zero Trust boundary so convenience does not turn into over-exposure.

 12

Troubleshooting and handover

Work through HA, the Web GUI, cloudflared, DNS and the Cloudflare edge in order, and leave a record you can hand over.
