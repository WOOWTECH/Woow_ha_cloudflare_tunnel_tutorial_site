第 2 章

安裝 Cloudflared Web GUI

把 WOOWTECH repository 加入 Home Assistant Apps 商店，確認來源與硬體相容後再安裝。這一章只讓 Web GUI 在空白設定下可開啟，不建立 Tunnel、不授權 Cloudflare，也不新增公開 hostname。

先把正確套件裝進正確的地方

Cloudflared Web GUI 不是 Home Assistant 的一般整合（Integration），而是由 Supervisor 管理的第三方 App（舊稱 add-on／附加元件）。你要先加入它的 repository，Apps 商店才會取得套件資訊與映像檔；把 GitHub 網址貼到整合頁、HACS 或瀏覽器網址列都不會完成安裝。

這章完成後：Apps 詳細頁會顯示 Cloudflared Web GUI，App 能啟動，而且你能從 Home Assistant 開啟 Web UI。設定保持空白時，WOOWTECH 文件說明 Web GUI 會繼續運作、Tunnel 則保持停止。
第三方軟體提醒：Home Assistant 官方明確表示無法保證第三方 Apps 的品質或安全性。安裝前核對 GitHub 組織、repository 完整網址與專案文件；不要安裝搜尋結果中名稱相似的套件。

Repository、App 與 Ingress 各做一件事

項目用途這一步會不會建立 Tunnel
App repository告訴 Home Assistant 到哪裡取得 App 清單與版本資料不會
安裝 App下載符合架構的映像檔並建立受 Supervisor 管理的 App不會
啟動 App啟動容器內服務；空白設定時 Web GUI 保持可用依本 fork 的文件，空白設定下 Tunnel 停止
Home Assistant Ingress讓 Web GUI 經 Home Assistant 登入與內嵌路徑開啟不會額外對外開 port
Setup 或 Config 儲存把值寫入 Supervisor options，並可能啟動設定流程可能會；本章不要做

這個 App 的 Web GUI 經 Ingress 使用容器內部 port 8099，專案設定沒有要求你把它映射到外部。Dashboard、Setup、Config、Logs 都是同一個 App 裡的管理頁，不需要為管理介面設定路由器 port forwarding。

不要自行公開管理介面：不要為 8099 新增路由器轉送、Cloudflare public hostname 或反向代理。正確入口是 Home Assistant App 詳細頁的 Open Web UI，或啟用後的側邊欄項目。

手動加入 repository 並安裝

  1. 確認你在正確的 Home Assistant

    先看瀏覽器網址與目前登入的 Home Assistant 名稱，避免在測試機或家人的主機安裝。到「設定」中的 Apps；不同語言或較舊版本可能顯示「附加元件／Add-ons」。如果完全沒有 Apps，先回第 1 章確認安裝類型。

  2. 進入 Apps 商店

    在 Apps 頁選擇安裝 App／App store。Home Assistant 版本不同時，入口文字可能略有差異；你的目標是看到可以搜尋 Apps、右上角有更多選單的商店頁。

  3. 開啟 Repositories 對話框

    選右上角三點選單，再選 Repositories（儲存庫）。不要在商店搜尋框直接貼網址，搜尋框只會篩選已知 Apps。

  4. 貼上唯一正確的 repository URL

    完整貼上下一段的 HTTPS clone URL，確認開頭是 https://github.com/WOOWTECH/、結尾是 Woow_ha_cloudflare_tunnel_webgui，再選新增。

    https://github.com/WOOWTECH/Woow_ha_cloudflare_tunnel_webgui

  5. 重新整理並核對 App 卡片

    關閉 repository 對話框後，如果商店尚未出現新卡片，先重新整理瀏覽器。找到 Cloudflared Web GUI 後，先進詳細頁閱讀說明，核對來源連回 WOOWTECH repository，不要只看圖示判斷。

  6. 安裝 App

    在正確的詳細頁選安裝，等待 Home Assistant 完成下載與建立。過程可能需要數分鐘，依主機與網路速度而定；不要反覆按安裝或在進行中關機。

  7. 保持空白設定並啟動

    安裝完成後先不要填 external_hostname、additional_hosts 或 tunnel_token，選啟動。依專案文件，完全空白設定會讓 Web GUI 保持可開啟、Tunnel 停止，正適合下一章做唯讀導覽。

側邊欄是選用捷徑：你可以開啟「顯示於側邊欄」方便日後進入；即使不開，也能從 App 詳細頁的 Open Web UI 進入。這個切換不等於把 Web GUI 公開上網。
本章停止點：看到 App 已啟動就停。不要在 Setup 按授權連結，不要在 Config 輸入 hostname 或 token，也不要按 Save & Restart。

快速連結或手動加入，怎麼選

方法優點使用前檢查
My Home Assistant repository 按鈕可帶你到自己的 Home Assistant，並預先帶入 repository URL先核對跳轉目標是你的主機，預填 URL 與官方 README 相同
Apps 商店手動加入每一步可見，適合確認主機與完整 URL只從專案 README 複製 URL，不從影片留言或短網址複製

對第一次操作的人，手動加入比較容易理解 repository 在哪裡，也方便排查網址是否貼錯。若使用 README 裡的 My Home Assistant 按鈕，仍要在最後確認畫面：自動帶入只省去輸入，不代表你可以跳過來源檢查。

安裝完成的驗收清單

  1. Repository 記錄正確

    Repositories 清單中的網址和本章程式碼區塊逐字相同，沒有多餘空白、錯字或相似 repository。

  2. App 確實已安裝

    Apps 清單能開啟 Cloudflared Web GUI 詳細頁，並顯示啟動、停止、設定或 Open Web UI 等 App 管理功能，而不是仍只有商店的安裝按鈕。

  3. App 能在空白設定下啟動

    啟動後 App 狀態沒有持續停在「啟動中」。完全空白設定時 Tunnel 未運作是這個 fork 的預期行為，不要為了消除提示而隨便填 hostname。

  4. Web UI 入口存在

    詳細頁可見 Open Web UI，或側邊欄已顯示 Cloudflared。現在只確認入口，不進行授權或儲存。

  5. 沒有額外網路變更

    你沒有新增路由器 port forwarding、Cloudflare DNS 記錄、public hostname 或反向代理規則。

  6. 沒有敏感資料外流

    你沒有公開 repository 以外的私人畫面；尤其未分享授權網址、Tunnel token、完整 Logs、帳號或內網 IP。

驗收通過：下一章會從 Ingress 第一次開啟 Web GUI，只辨識 Dashboard、Setup、Config、Logs，不儲存任何內容。

安裝時常見卡關

  1. Repositories 選項不存在

    確認你在 Apps 商店頁，不是「裝置與服務」、HACS 或某個 App 的設定頁。若整個 Apps 功能都沒有，查安裝類型；不要嘗試用 HACS 取代 Supervisor App。

  2. 新增後看不到 App

    依 Home Assistant 官方建議先重新整理瀏覽器，再回到 Apps 商店查看。仍未出現時重新核對 repository URL；第三方 repository 若設定資料無效，也可能無法顯示。

  3. 顯示不支援或沒有可安裝版本

    比較系統架構與專案目前支援的 aarch64、amd64。架構不符時停止，不要下載別的架構映像檔硬裝。

  4. 安裝長時間沒有完成

    先保持主機供電與網路穩定，稍後回 App 詳細頁確認狀態；再查看 Supervisor 相關系統日誌中的下載或儲存空間錯誤。分享錯誤前遮罩主機名稱、IP、repository 私人資訊與任何憑證。

  5. 啟動後又停止

    先確認安裝的是 WOOWTECH Web GUI 版本，再從 App 詳細頁讀最新幾行日誌。空白設定的這個 fork 應保留 Web GUI；若仍停止，記下版本、架構與已遮罩錯誤，不要先填假 hostname 或 token。

  6. Open Web UI 按鈕無法使用

    確認 App 已完成啟動，重新整理 Home Assistant 後再試；也可暫時關閉再開啟側邊欄顯示選項。不要改用直接連線 8099，Ingress 才是受 HA 登入保護的入口。

安裝常見問題

Cloudflared Web GUI 是 Home Assistant 官方 App 嗎？
不是。它是 WOOWTECH 維護的第三方 repository，Tunnel 核心 fork 自上游 homeassistant-apps/app-cloudflared。Home Assistant 官方也提醒第三方 Apps 需自行評估品質與安全。
可以從 HACS 安裝嗎？
不可以用 HACS 取代本章流程。這是 Supervisor 管理的 App，要從 Home Assistant Apps 商店加入 repository 後安裝。
安裝後一定要立刻填 hostname 嗎？
不用。這個 fork 的特別行為就是完全空白設定時保留 Web GUI、停止 Tunnel，讓你先開介面完成首次規劃。不要為了讓畫面「看起來完整」而輸入假資料。
需要在路由器開 8099 或 8123 嗎？
不需要。8099 是 Web GUI 的 Ingress 內部 port；Cloudflare Tunnel 由 connector 主動對外建立連線。本指南不要求新增 Home Assistant 的入站 port forwarding。
現在可以按 Save & Restart 試試看嗎？
不要把它當測試按鈕。它會寫入 Supervisor options 並重啟 App，可能接著開始登入、建立 Tunnel 或改 DNS。等後續章節核對正式設定後再操作。
更新 Home Assistant 後選單名稱不同，代表流程失效嗎？
不一定。官方英文介面由 Add-ons 改稱 Apps，翻譯與按鈕位置可能隨版本調整。依「設定 → Apps → App 商店 → Repositories」的功能目的尋找，並以 Home Assistant 最新官方文件為準。
