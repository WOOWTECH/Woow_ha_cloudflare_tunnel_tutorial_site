Home Assistant Cloudflared Web GUI 指南

不開埠，安全連回家

12 章繁體中文 Cloudflared Web GUI 教學：從安裝、Setup、Cloudflare 授權、hostname、Dashboard、Config、Logs，到安全與排錯。

從課程地圖開始

12 chapters · one secure tunnel

用清楚的順序，建立你的安全入口

先確認網域與 Home Assistant，再理解 Setup、授權和 hostname；完成後用 Dashboard、Config 與 Logs 建立可驗證、可回復的維護節奏。

  1. 先建立入口安裝 Web GUI 並確認前置條件。
  2. 再完成建置理解授權、hostname 與 Tunnel 狀態。
  3. 最後守住邊界用 Logs、安全檢查與排錯維持服務。

基礎：準備與安裝

01

開始前

先確認網域、Cloudflare DNS、Home Assistant 安裝方式與本地／遠端管理模式。

 02

安裝 Web GUI

將 WoowTech repository 加入 Apps 商店，安裝套件並保留安全的初始狀態。

 03

第一次開啟

從 Home Assistant Ingress 開啟介面，認識 Dashboard、Setup、Config 與 Logs。

建置：建立安全入口

04

Setup 精靈

用精靈整理 hostname、Tunnel 模式與授權前置條件，不急著按下套用。

 05

Cloudflare 授權

辨識一次性授權網址、正確選擇網域，並避免洩漏憑證或授權連結。

 06

Dashboard 狀態

讀懂 tunnel、edge connections 與 add-on 狀態，先觀察再決定是否處理。

管理：主機與日誌

07

Config 設定

理解 Web GUI 與 Supervisor options 的同步關係，分清每個設定的影響範圍。

 08

External hostname

規劃 Home Assistant 對外 hostname、trusted proxy 與端到端驗收。

 09

Additional hosts

只公開真正需要的內網服務，理解 hostname、service 與刪除後的 DNS 清理。

維護：安全與排錯

10

Logs 與維護

用即時日誌、過濾與下載功能建立可重複的健康檢查流程。

 11

安全檢查

檢查入口、帳號、hostname、DNS 與 Zero Trust 邊界，避免把方便變成過度公開。

 12

排錯與交接

依序檢查 HA、Web GUI、cloudflared、DNS 與 Cloudflare edge，留下可交接記錄。
